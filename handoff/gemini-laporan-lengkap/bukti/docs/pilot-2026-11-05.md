# Pilot terkontrol — 5 November 2026, Asia/Jakarta

Pengguna meminta seluruh tahap dikerjakan dan hasilnya diperiksa Codex, kemudian
menetapkan batas Flow maksimal 25 kredit total. Rancangan utama tetap: Codex membangun,
Hermes mengeksekusi, identitas/memori tiga karakter terpisah, Omni Flash x1, editing
lokal, review versi final dan publikasi berizin. Pilot ini tidak mengaktifkan operasi
tanpa pengawasan atau menghapus kebutuhan ACC.

## Hasil yang sudah dibuktikan

- Model Hermes Dinda memakai MCP untuk list_pages, select_page dan take_snapshot pada
  proyek yang benar. Uji pertama gagal karena tab target tidak terbuka, lalu berhasil
  setelah Codex membuka URL proyek yang sudah dipetakan.
- Hermes menjalankan dua web_search dan satu web_extract melalui konfigurasi Exa free.
  Tiga sumber disimpan di shared/research/2026-11-05-dinda-pilot.json dan katalog SQLite.
  Bukti tren TikTok belum cukup; hasil adalah kandidat dan konteks, bukan klaim viral.
  Ide burgo dari Hermes tetap draf dan tidak dipakai untuk produksi harian.
- Katalog lokal membedakan ID video yang sama, video baru dengan ID sound sama, dan URL
  baru. Observasi bertanggal dipertahankan. Kemiripan konsep masih penilaian model.
  Short link tidak dianggap sama sebelum URL akhirnya benar-benar diketahui.
- FFmpeg 7.1.1 dan FFprobe berhasil dijalankan dari runtime yang sudah dibundel Android
  Studio. Homebrew install gagal karena direktori tidak writable; tidak ada chown/sudo
  atau perubahan global. Runtime lokal sekitar 45 MiB. Dua klip sintetis berhasil
  disambung, dipotong dan didekode. Penambahan teks belum diuji.
- Hermes menyiapkan dan menjalankan satu pilot TEKNIS identitas Dinda, terpisah dari
  konten harian yang memerlukan bukti tren. Referensi ekspresi Dinda sudah diperiksa
  Codex dan dilampirkan Hermes. Pengaturan: Omni 1.1 Flash, Ingredients, 9:16, 720p,
  6 detik, x1, estimasi 10 kredit. Tidak ada foto awal tambahan atau retry.
- Generasi terlihat berjalan dan selesai. Hermes mengunduh pilihan 720p Original size.
  Asset Flow: 060b02c5-e2b4-4895-93e8-fe609750c54e.
- Saldo aktual yang diperiksa Codex: 468 sebelum, 458 sesudah. Biaya dicatat 10 kredit.
  Sisa batas pilot 15 kredit; izin generate baru kembali ditutup, tidak ada retry.
- File asli 720x1280 H.264 berdurasi container 6.037333 detik, dengan satu audio stream.
  Export lokal v1 tanpa audio berdurasi 5.966667 detik, 180 frame. Original dipertahankan.
- Codex membandingkan master dengan frame 0.25, 2.75 dan 5.5 detik. Satu subjek, hijab,
  baju, pendant dan progres ekspresi terlihat konsisten secara umum. Tidak ada kolase
  atau teks referensi yang ikut tampil. Tangan di luar frame, sehingga tidak dinilai.
  Ini QA sampel dasar, bukan jaminan identitas/gerakan sempurna di seluruh frame.
- Telegram getMe dan getWebhookInfo lulus; tidak ada webhook aktif. Pesan tes, dokumen
  final, caption lengkap dan kartu tombol review berhasil terkirim. Callback ACC dari
  pengguna kemudian diterima dan tersimpan SATU kali walau beberapa klik masuk.
  approved_package memeriksa ulang byte/hash media dan caption. Kartu diperbarui
  menjadi ACC tersimpan dan tombol dihapus. Review: f76c83d5f3ba4bb9a6f624bc900c570c.
  Penerima masih sekali panggil, sehingga tidak menjanjikan respons seketika saat
  tidak ada proses pemeriksaan aktif. Tidak ada publikasi terpicu.
- Codex menguji TikTok Studio akun @dinda.kemala_: upload selesai, caption tes dipasang,
  visibilitas Only you dipilih dan label AI diaktifkan. Draf tersimpan dan terlihat pada
  https://www.tiktok.com/tiktokstudio/content?tab=draft. Tombol Post tidak ditekan.
- Editor web TikTok memiliki pencarian Sounds. Dua pencarian LEU dan original sound -
  LEU menampilkan hasil tanpa kecocokan tepat. Ini bukan bukti sound tidak tersedia
  secara global. Sound lain tidak disubstitusikan; attachment dan pemilihan segmen
  audio belum diuji. Operasi TikTok ini oleh Codex, belum oleh Hermes.

## Batas implementasi yang masih nyata

Belum ada publikasi terkonfirmasi atau adapter publikasi teruji. Paket pilot berlabel
belum untuk publikasi; ACC terhadap pilot tidak menyalakan posting. Tidak ada kejadian
canon ditambahkan. Jalur sound yang cocok, pemilihan segmennya dan validasi paket
setelah editing platform perlu dibuktikan sebelum operasi rutin.

Nara dan Rania belum diuji memakai model/browser masing-masing; dua akun Flow lain
belum selesai diverifikasi/dipetakan. Tidak ada scheduler baru dipasang atau diaktifkan.
Jadwal Codex lama tetap PAUSED. Alur harian tidak dimulai tanpa kelulusan prasyarat.

Pengujian lokal terbaru: 44 unit tests lulus, ditambah uji decode/join/trim media dan
integrity/foreign-key check database. scripts/check_setup.py kini memahami mode
controlled_pilot dan memeriksa batas 25 kredit, tanpa mengasumsikan database kosong.

## Penggunaan model dan efisiensi

Pemakaian dilaporkan Hermes per sesi dan merupakan penjumlahan token lintas panggilan,
bukan panjang satu halaman. Angka cache_read termasuk dalam input, bukan tambahan:

| Sesi | Input | Output | Cache read |
|---|---:|---:|---:|
| Baca Flow berhasil | 34.881 | 224 | 18.560 |
| Riset terbatas | 30.617 | 1.648 | 11.520 |
| Persiapan formulir berhasil | 511.599 | 1.085 | 446.976 |
| Submit satu generasi | 90.070 | 373 | 48.000 |
| Unduh hasil | 59.831 | 346 | 45.696 |

Sesi persiapan masih terlalu banyak langkah untuk dijadikan acuan operasi hemat.
Ini pengukuran pilot, bukan janji biaya harian. Sebelum penjadwalan, kurangi pembacaan
ulang halaman/konteks dan satukan langkah produksi yang sudah diketahui. Jangan
mengonversi angka ini menjadi harga rupiah atau menyamakannya dengan kredit Flow.

## Status akhir yang diinginkan setelah tes

Generasi baru, publikasi, autopilot dan scheduler nonaktif. Telegram dapat diperiksa
dengan receive-once secara eksplisit tanpa daemon. Worker/gateway sementara khusus
Dinda dihentikan; gateway default tidak direstart. Konektor input pilot dihapus dari
konfigurasi Dinda dan toolset CLI dikosongkan; konektor baca yang sudah ada dipertahankan.
Konfigurasi awal profil dicadangkan di home profil, tanpa menyalin token ke proyek.

Artefak bukti berada di operations/reports, rencana teknis di operations/plans,
status/versi/ACC di operations/production.sqlite, dan media di content karakter.
